# OverDeathDangeon

手書き風の一人称ダンジョンRPG試作です。

> リポジトリ名は現状 `OverDeathDangeon` です。英語表記としては `OverDeathDungeon` が自然なので、公開前に変更する余地があります。

## 現在の段階

正式な「要件定義 → 基本設計 → 詳細設計 → 実装 → 検証」の完成版ではなく、まず遊べる最小プロトタイプでゲームの核を確認する段階です。

確認する核は、

1. 洞窟に入る
2. 落盤で閉じ込められる
3. ダンジョンを探索する
4. 敵に負ける
5. 死に戻りで強化される
6. 再挑戦して敵を倒す
7. 回復薬を拾う
8. メニューから回復薬を使う
9. 出口へ進む

です。

## ブランチ方針

- `main`: 安定版・公開用
- `prototype/v0`: 最初のプロトタイプ

## prototype/v0 の内容

- スマホ縦画面想定
- HTML / CSS / JavaScript の静的ゲーム
- GitHub Pagesで公開可能
- 5×5のコの字チュートリアルマップ
- 操作は「左を向く」「前進」「右を向く」の3つ
- 現在地と向きから一人称ダンジョン画面を描画
- 左右前方の壁、現在左右の壁、正面壁を参照
- 敵、回復薬、出口のチュートリアル文
- 回復薬は拾った後、下部の「アイテム」メニューから使用
- 下部の「ステータス」ボタンで詳細ステータスを確認
- 初期HP34、攻撃5、レベル1
- 最初の敵には必ず負ける
- 死に戻りで最大HPと攻撃力が上昇
- 死に戻りではレベルは上がらない
- 敵撃破時にレベル上昇
- 死亡回数、読込回数を記録
- 手動保存と自動保存を分離
- 画面下部の「読込」は手動保存地点に戻る
- タイトルの「セーブから再開」は最新の手動保存または自動保存から再開
- localStorageによる保存、読込、初期化
- 仮実績：初回踏破、不死踏破、理論値踏破、死還者

## 遊び方

`index.html` をブラウザで開きます。スマホ縦画面を想定しています。

基本ルート：

1. 東へ2マス進む
2. 南を向く
3. 敵に接触して1回負ける
4. 死に戻り後、同じ敵を倒す
5. 南へ進む
6. 西を向く
7. 回復薬を拾う
8. 「アイテム」から回復薬を使う
9. 出口へ進む

## 実装メモ

`game.js` は、次の処理が混ざりすぎないように分けています。

- `MapState`: マップ定義
- `state.player`: プレイヤー位置と向き
- `state.stats`: HP、攻撃、レベル
- `state.progress`: 敵撃破、薬取得、クリア状態
- `movement`: 移動処理
- `battle`: 戦闘処理
- `beginDeathReturn` / `applyDeathReturn`: 死に戻り処理
- `renderDungeon`: 一人称描画
- `saveGame` / `loadGame`: セーブ処理

`patch.js` は、既存の動作を崩さずに以下を追加する小さな修正層です。

- 手動保存と自動保存の分離
- 手動読込の復元処理
- 回復薬の拾得形式
- アイテムメニュー
- ステータスメニュー

次に拡張する場合は、まずこの5×5チュートリアルが安定して動くことを確認してから、ステージ追加・敵追加・演出追加に進む方針です。
