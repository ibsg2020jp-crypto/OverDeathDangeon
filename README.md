# OverDeathDangeon

`prototype/v1-clean` は、壊れた `prototype/v0` を延命せず、`main` から作り直したクリーン版です。

## 方針

- 旧 `prototype/v0` の継ぎ足し修正は使わない
- `patch.js` 方式をやめる
- `index.html` / `style.css` / `game.js` の3本を直接つなぐ
- ボタン処理、保存読込、アイテム、ステータスを最初から同じ `game.js` 内で管理する

## 実装内容

- スマホ縦画面の一人称ダンジョンRPG
- 5×5のコの字チュートリアルマップ
- 操作は「左を向く」「前進」「右を向く」
- 敵に初回敗北し、死に戻りで強化
- 2回目は敵を倒せる
- 回復薬は拾得後、「アイテム」メニューから使用
- 「ステータス」ボタンで詳細確認
- 手動保存と自動保存を分離
- 下部の「読込」は手動保存地点に戻る
- タイトルの「セーブから再開」は最新の保存から再開
- 主人公の表情素材を新しい `assets/face-*.svg` に差し替え
- 一人称描画は `viewCell(depth, side)` で前方・左右前方・現在左右を判定

## 確認すること

1. 「アイテム」「ステータス」ボタンが反応する
2. 回復薬を拾う前は、アイテム欄に何もない
3. 回復薬を拾った後、アイテムから使用できる
4. 「保存」→移動→「読込」で保存地点に戻る
5. キャラ表情が場面ごとに変わる
6. 横前方の壁が一人称画面に反映される

## ブランチ

- 安定版: `main`
- 作り直し版: `prototype/v1-clean`
- 旧試作: `prototype/v0` は使わない
