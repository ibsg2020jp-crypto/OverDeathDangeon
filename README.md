# OverDeathDangeon

手書き風の一人称ダンジョンRPG試作です。

## 現在の段階

正式な「要件定義 → 基本設計 → 詳細設計 → 実装 → 検証」に入る前に、まず遊べる最小プロトタイプで感触を確認します。

## ブランチ方針

- `main`: 安定版・公開用
- `prototype/v0`: 最初のプロトタイプ

## prototype/v0 の内容

- 洞窟に入るプロローグ
- 落盤イベント
- 主人公の表情つき会話
- 5×5の簡易ダンジョン
- HP、死亡回数、ロード回数の記録
- 敵、回復薬、出口
- 死亡時の初期位置帰還と能力上昇
- 死亡回数・ロード回数による仮実績
